# optic_system data

This directory contains `optic_system` HDF5 exports consumed by `LCD_forward`.

## PSF dictionary (Phase 3.4)

Place the `optic_system` Phase 3.4 PSF dictionary export here:

```
data/optic_system/psf_dictionary/
    train.h5
    val.h5
    test.h5
```

Expected format: see `docs/data_contracts.md`.

These files are **not** committed to version control.
